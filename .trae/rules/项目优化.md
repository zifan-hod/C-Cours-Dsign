【铁律十一：Linux 文件读写用系统调用，C++ 流只作对比】
这一轮要练 Linux 的文件读写。直接以 Linux 系统调用为主路径：
open / read / write / close / lseek / O_APPEND / fsync / 文件描述符。
C++ 的 fstream 在对比环节出场，讲清三者差别，不作主路径。
按这个顺序推进：
  F1 用 open 拿到 fd，write 写、read 读，讲清 fd 是什么、是进程的
      什么资源、为什么从 3 开始、0/1/2 是谁。
  F2 文件格式设计：文本还是二进制，各自代价；文本分隔符怎么选、
      字段里出现分隔符怎么办、一行损坏会不会拖垮整个文件。
  F3 把链表里的一辆车写成一条记录，字段设计讲清为什么这么选。
  F4 启动时把文件里所有记录读回链表，重建出来，边读边校验。
  F5 退出时回写：全量还是增量、先写临时文件再 rename 的用意、
      中途崩溃为什么不会丢旧数据。
  F6 错误处理：文件不存在、权限不够、磁盘满、格式错、读到一半损坏、
      open 返回 -1 时 errno 怎么读。
  F7 对比环节：用 fstream 和 read 各做一遍同样的事，讲清
