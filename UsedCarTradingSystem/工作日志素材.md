**完成内容：**

1. 逐个实现循环双链表成员函数：判空、求长度、取元素、按值查找、插入、删除、遍历
2. 编写链表专项测试程序 test_linklist（用 `DoubleLinkList<int>`，不掺业务代码）
3. 定位并修复删除、遍历函数中的逻辑错误，测试全部用例通过、无段错误

**问题与解决：**

- 错误 1：`while (p->next != head && p = p->next)` 编译报错（赋值左值必须是左值）
  → 原因：`&&` 优先级高于 `=`；解决方案：加括号 `(p = p->next)`，最终改为标准 while 循环
- 错误 2：ListDelete 运行后链表出现垃圾值、最终段错误
  → 原因：改链之后才 `delete s->next`，此时 s->next 已指向新接上的节点，删错节点；删尾时甚至 delete 了 head
  → 解决方案：**改链之前**先用临时指针 `del` 存住被删节点，取数据、摘链后 `delete del`；通用写法不再区分头尾
- 错误 3：ListTraverse 写死 `cout << p->data`，visit 参数未使用
  → 解决方案：函数体只写 `visit(p->data);`，"做什么"由调用方决定

**问题与解决：**

- 疑问：链表节点要不要设最大数量、怎么扩容？
  → 结论：链表每节点独立 new，容量只受系统内存限制，不存在"满"和"扩容"；扩容是数组型结构（顺序表、循环队列）才有的问题

### 2026.09.21（第 2 周）

**完成内容：**

1. 完成 Car::FromLine：find(':') 循环切字段 + ostringstream 拼串 + istringstream 读取
2. 往返测试 10 个字段全部一致，Car 模块验收通过

**问题与解决：**

- 错误 1：`if (pos == npos)` 编译报 npos 未声明
  → 原因：`using namespace std;` 只释放 std 中的名字，npos 是 `string` 类的嵌套成员，不是 std 中的独立名字
  → 解决方案：写 `string::npos`
- 错误 2：createTime 往返只剩日期 `[2026-09-20]`
  → 原因：`>>` 按空格切分，时间值内部含空格，读到空格即停
- 错误 3：改为"日期+时间"两段读后，实际只得到 `[2026-09-20 01]`
  → 原因：切分循环"见冒号就换空格"，把时间内部的 2 个冒号也换了，时间被拆成 `01 27 37` 三个 token
  → 解决方案：createTime 按 4 段（日期+时分秒）读出，拼回时补回冒号
- 经验总结："替换分隔符 + >>"方案要求字段值内部不含被替换符号；一行有 11 个冒号（9 个分隔 + 2 个在时间内），转换前必须认清
